# 🚀 Review Form - Quick Reference Card

## ⚡ 30-Second Summary

**You can now leave reviews!** After purchasing an architecture:

1. Click **"✍️ Write a Review"** button
2. Select **star rating** (1-5 stars) 
3. Type optional **comment** (max 500 chars)
4. Click **"✓ Submit Review"**
5. ✅ Done! Listing rating updates automatically

---

## 📋 Quick Checklist

- [ ] **Purchase** architecture (required)
- [ ] Click **"Write a Review"** button
- [ ] **Select rating** ⭐⭐⭐⭐⭐ (required)
- [ ] **Type comment** (optional, max 500 chars)
- [ ] Click **"Submit Review"**
- [ ] See success message ✅
- [ ] Listing rating updates 📊

## 🎯 Rating Guide

| Stars | Meaning | When to Use |
|-------|---------|------------|
| ⭐ | Poor | Doesn't work / Not recommended |
| ⭐⭐ | Fair | Some issues / Needs improvement |
| ⭐⭐⭐ | Good | Works well / Average quality |
| ⭐⭐⭐⭐ | Very Good | Excellent / Highly recommend |
| ⭐⭐⭐⭐⭐ | Excellent | Perfect / Outstanding work |

## ⚠️ Rules

| Rule | What It Means |
|------|--------------|
| 🔒 Must Purchase | Can't review without buying |
| ⭐ Rating Required | Must select 1-5 stars |
| 💬 Comment Optional | Can rate without comment |
| 👤 One Per User | Each user = 1 review per listing |
| ✏️ Can Update | Submit again to change review |
| 📧 Need Login | Must be signed in |

---

## ❌ Common Issues

### "Must purchase before reviewing"
→ Click Purchase button first

### "Please select a rating"
→ Pick a star rating from dropdown

### "Please login to submit a review"
→ Login to your account

### "Failed to submit review"
→ Check internet connection, try again

---

## 📍 Where to Find It

1. Click **🛒 Marketplace** (header)
2. Browse & click architecture
3. Click **"Purchase"** or **"Get for Free"**
4. Button **"✍️ Write a Review"** appears
5. Click it to open form

---

## 🔄 Update Review

**Want to change your review?**

Simply click "Write a Review" again and submit the new rating/comment. Your previous review is automatically updated!

---

## 📊 What Happens After Submit

✅ Review saved to database
✅ Listing rating recalculated
✅ Review count increases by 1
✅ Success message shown
✅ Form closes and resets
✅ Listing rating updates on screen
